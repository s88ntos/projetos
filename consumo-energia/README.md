# Calculadora do consumo de energia de seus aparelhos eletrônicos no estado de São Paulo

Este projeto em Python foi criado para ajudar os cidadãos do estado de São Paulo a estimar o gasto de energia de cada aparelho em suas casas.

O programa pergunta qual aparelho você deseja calcular, sua potência e o tempo médio de uso diário.

Com essas informações, ele calcula o consumo multiplicando a potência pelo tempo de uso diário, depois por 30 (dias do mês) e dividindo por 1000 para converter em kWh.

Para o estado de São Paulo, o resultado é multiplicado por 0,70, que corresponde ao valor médio do kWh.

Assim, basta informar o aparelho, a potência e o tempo de uso diário para obter uma estimativa do gasto de energia de cada aparelho eletrônico.
